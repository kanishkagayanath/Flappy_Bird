# 🐦 Flappy Bird

Welcome to **Flappy Bird** – a classic 2D game recreated for desktop! 🎮  
Fly your bird through the pipes and challenge yourself to beat your high score!

## ✨ Features

- 🐤 Simple and addictive 2D gameplay
- 🏆 Score tracking
- 🎨 Colorful graphics
- 💻 Desktop application – ready to play!

## 📥 Download & Play

Download the playable game file from the [Releases page](https://github.com/kanishkagayanath/Flappy_Bird/releases).  
Just run the downloaded file to start playing Flappy Bird instantly!

## 🛠️ Technologies Used

- ShaderLab
- HLSL
- C#
